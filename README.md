🏠 املاک DOT



سامانهٔ مدیریت فایل املاک که روی GitHub زندگی می‌کند،
با دیوار حرف می‌زند، رهن را مثل شعبده‌باز به اجاره تبدیل می‌کند،
و گاهی مثل یک مشاور پرحوصله می‌گوید:
«این مستأجر به آن خانه می‌خورد — زنگ بزن.»



این چیه‌ اصلاً؟

املاک DOT یک اپ وب سبک (بدون سرور اختصاصی) برای مشاور املاک است.





فایل‌ها روی ریپوی گیت‌هاب ذخیره می‌شوند (data/files.json)



شماره‌ها با کلید مشتق‌شده از توکن رمز می‌شوند



می‌توانی از لینک دیوار آگهی بیاوری



ماشین‌حساب رهن/اجاره و کمیسیون داری



و قابلیت تطبیق که پیشنهاد می‌دهد کی به کی نزدیک‌تر است

انگار دفتر املاک را داخل مرورگر جمع کرده‌ای — بدون اجارهٔ سرور، فقط با یک Token و کمی جادوی فرانت.

سه حالت:





رهن‌کامل
رهن + اجاره با نرخ پیش‌فرض ۳ میلیون اجاره ≈ ۱۰۰ میلیون رهن به رهن کامل تبدیل و مقایسه می‌شود.



رهن و اجاره
رهن با رهن، اجاره با اجاره — بدون تبدیل.



خرید / فروش
سرمایهٔ خریدار در برابر قیمت فروش.

قوانین امتیاز (ساده و صادقانه)





امتیاز فقط از روی قیمت است (نزدیک‌تر = بالاتر).



منطقه و متراژ در امتیاز دخالت ندارند.



امکانات (پارکینگ، انباری، آسانسور، …) فقط وقتی فیلتر شوند، شرط می‌شوند.



هر پیشنهاد یک وضعیت پیگیری دارد: باز / پیشنهاد شد / تماس / رد / توافق (روی همان دستگاه ذخیره می‌شود).

کارت‌ها گروهی‌اند: برای هر مستأجر/خریدار یک کارت، زیرش لیست پیشنهادها.



🚀 راه‌اندازی سریع

پیش‌نیاز





یک ریپوی GitHub (خصوصی یا عمومی)



یک Personal Access Token با دسترسی Contents: Read and write روی همان ریپو



فایل داده در مسیر تنظیم‌شده (پیش‌فرض data/files.json)

تنظیمات

در js/config.js:

export const CONFIG = {
  owner: "amlakdot",           // مالک ریپو
  repo: "file",               // نام ریپو
  branch: "main",
  dataPath: "data/files.json",
  publicDataPath: "data/public-files.json",
  divarProxy: "https://....workers.dev", // پروکسی CORS دیوار
  sessionDays: 7
};

اجرا

چون ماژول ES است، بهتر است با یک سرور استاتیک باز شود (نه file://):

# مثال
npx serve .
# یا
python3 -m http.server 8080

بعد برو به index.html، توکن را بزن، و برو تو کار.

صفحهٔ عمومی: public.html

🔐 امنیت (کوتاه و جدی)





توکن GitHub روی دستگاه ذخیره می‌شود؛ مثل کلید گاوصندوق است — به کسی نده.



شماره‌ها با کلید مشتق‌شده از توکن رمز می‌شوند؛ بدون توکنِ درست، خوانا نیستند.



صفحهٔ عمومی عمداً نام و تلفن ندارد.



این پروژه جایگزین کنترل دسترسی سازمانی نیست؛ برای تیم کوچک/شخصی طراحی شده.



🧱 دیوار و پروکسی

دیوار از مرورگر مستقیم CORS نمی‌دهد؛ برای همین divarProxy لازم است (مثلاً Cloudflare Worker).

اگر دیدی:



دریافت آگهی از دیوار ناموفق بود / درخواست منقضی شد

اول پروکسی، بعد اینترنت، بعد لاگ‌های داخل منو (⋮ → لاگ‌ها) را چک کن.
